# Jenkins CI/CD – Continuous Integration and Continuous Delivery

A comprehensive hands-on learning repository covering **Jenkins, Continuous Integration (CI), Continuous Delivery (CD), Continuous Deployment, Pipeline Automation, and DevOps practices**.

Learn how to automate software build, testing, code quality analysis, security scanning, packaging, and deployment using Jenkins. Explore Jenkins installation, configuration, architecture, plugins, agents, distributed builds, Freestyle projects, Pipeline as Code, and Declarative and Scripted Pipelines through practical examples and real-world projects.

Integrate Jenkins with industry-standard DevOps tools such as **Git, GitHub, Maven, Gradle, SonarQube, Nexus, Artifactory, Docker, Kubernetes, Ansible, Terraform, AWS, and Argo CD** to build end-to-end CI/CD pipelines.

This repository also covers Jenkins security, credentials management, webhook integration, shared libraries, pipeline notifications, automated testing, deployment strategies, monitoring, and troubleshooting.

Designed for beginners and experienced DevOps engineers who want to master Jenkins and build reliable, scalable, and fully automated CI/CD pipelines.

## Learning Objectives

By working through this repository, you will learn how to:

- Install, configure, and administer Jenkins.
- Create and manage Freestyle and Pipeline jobs.
- Write Declarative and Scripted Jenkinsfiles.
- Integrate Jenkins with GitHub and other DevOps tools.
- Automate application builds, testing, and deployments.
- Build and publish Docker images.
- Deploy applications to Kubernetes and AWS.
- Integrate code quality and security scanning into CI/CD.
- Manage credentials, agents, plugins, and shared libraries.
- Build end-to-end production-style CI/CD pipelines.

**Goal:** Master Jenkins CI/CD automation and gain practical experience building secure, reliable, and scalable software delivery pipelines.
